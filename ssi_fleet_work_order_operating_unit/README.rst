=================================
Fleet Work Order + Operating Unit
=================================

Glue module that adds Operating Unit support to the Fleet Work Order
module. Extends ``fleet_work_order`` with ``mixin.single_operating_unit``,
so that fleet work orders can be scoped and restricted per operating unit.


Installation
============

This module depends on:

* ``ssi_fleet_work_order``
* ``ssi_operating_unit_mixin``
